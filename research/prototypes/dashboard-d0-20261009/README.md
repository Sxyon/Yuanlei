## 连续任务

1. 管理概览进入治理工作台；编辑合成蓝图后切换议题，再返回蓝图核对草稿。议题 T1 当前决定 D1/r2 进入 W1，切 R1/R2，对照提交时要求和当前要求；分别输入意见，模拟409，打开文件再返回，意见与准确结果仍保留。返回来源回治理工作台。
2. 从平台收件箱打开乙项目同名交付，核对乙身份与空白独立意见，再返回原收件箱。切换通知已读和归档，Q2 仍为已答未恢复。问题页显示逐级回溯；恢复按钮只模拟准确尝试，真实能力待 C0/C5。
3. 模板库派生“经营观察”到甲项目；注入非法定义后验证，确认具体位置与启用禁用。恢复合法，模拟竞争更新→保存409→读取最新并保留→显式保存→验证→准确草稿预览。回管理后启用，再设业务首页。
4. 业务观察选择8月、切换缺数/错误，确认缺数不画0和管理可达；全屏→准确 R2→返回恢复月份、实例修订与全屏。退出全屏，库模拟发布v2，已有实例仍v1；升级形成草稿、启用后回退，稳定模板版本随修订恢复。当前首页归档被拒；选择替代后软归档保留历史。
5. 自主 stack 定义验证/预览，对照模板 grid 的不同结构；切乙项目时保留其本地实例与绑定。项目 Agent 页辨认接收、异常、交付和求助，避免把 Run 成功当验收。

## 已实现的模拟与限制

可操作：页面路由、项目切换、主题、合成意见/蓝图/讨论草稿、人工任务行、列表筛选、通知阅读/归档、定义有限校验、竞争状态、实例选择/派生/首页/软归档、稳定修订与模板版本回退、草稿预览、月份与源状态、全屏及准确交付往返。布局是手写示意，不是执行 examples.json 的通用 Vue renderer。草稿模拟没有文本合并器；库 v2 只演示锁定版本，不提供真实 v2 包差异。回退只演示稳定修订及模板锁定版本，真实绑定/定义/验证完整快照未实现。

展示位置但未执行：治理全部维护动作、议题检索和选中其他议题、工作看板/甘特、真实文件预览/权限、接收配置/日志、个人模板提取后的持久库、数据集采纳、自动授权与发布、真实刷新、失效对象/版本切换完整恢复、滚动与焦点返回。分栏/长页按钮展示同场景后果说明，没有重做两个完整治理应用。全屏是宿主布局模拟，未调用产品/浏览器真实全屏契约；规则预算、严格类型/字段完整校验、source授权、CAS和事务均未实现。R2 只链接既有对照判断，没有新增生成代码运行能力。

此稿只作设计审阅。作者 DOM 与视觉自查见基线 §12；没有人类使用观察，真实触屏、辅助技术和产品任务结果均未验证。
