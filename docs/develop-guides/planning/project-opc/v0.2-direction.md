# Project 规划 V0.2 方向修正

记录日期：2026-09-10。状态：后续版本的方向记录，完整 V0.2 规划尚未展开。

本文面向继续推进 Project 工作的用户与规划者，只保存本轮已经明确的修正。背景见 [V0.1 整体规划](./v0.1-overview.md)与[场景详解](./v0.1-scenarios.md)，版本入口见[归档说明](./README.md)。本文不增加新的产品机制、开发任务或首版能力清单。

## 本轮确定的方向

组织可以从实际工作开始，岗位、职责和协作方式在运行中形成。事业部不需要预先设计好全部边界、约束和完整岗位体系，才能开始工作。后续设计应允许信息不完备、少量角色兼任，以及根据真实问题逐步调整分工。

事业部的目标和战略允许变化。蓝图、规划和计划描述特定阶段的判断，随着实际情况、工作成果和用户决定动态调整。已有规划为行动提供参考，后续工作可以修订或替换不适用的内容。

产品和代码架构优先支撑最小可执行版本上线，在真实使用中逐步完善。V0.1 的完整目标形态提供方向感，不作为首次上线的前置清单；本轮没有确定最小版本包含哪些功能，也没有新增排期或实施方案。

ARBP 只约束在事业部体系下，不在公司级或更高层级开展组织建设。平台可以提供 ARBP 智能体类型，各事业部据此设立本事业部的 ARBP 数字员工。类型可复用，任职员工的工作、业务背景和记录归属所在事业部。

V0.1 归档稿已纳入这个明确的 ARBP 范围修正，并在开头注明；此前讨论的公司级 ARBP 建设设想不作为后续方向。其余整体构想继续作为可调整的初版参考，不能仅因出现在文档中就升级为固定产品要求。

本轮工作到归档为止，结束顶层构想的继续扩展。后续完善、最小版本选择和开发工作等待用户下一步指示。
