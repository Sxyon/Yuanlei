# 智能体快捷切换的搜索与滚动

状态：implemented
类型：bug-fix
Owner：web/src/views/AgentView.vue

## 问题

聊天输入区的智能体快捷切换将全部选项直接排列在弹层内。智能体较多时，弹层超出视口，末尾选项与管理入口无法方便访问。

## 决策

AgentView 参考模型选择器的顶部搜索和列表滚动结构。搜索按名称匹配，忽略首尾空格与大小写；无结果时显示提示，打开或关闭弹层时清空关键词。弹层高度上限为 420px，并保留视口边距；只有选项列表滚动，搜索、对话绑定提示与管理操作保持可见。搜索筛选由 AgentView 拥有；面板、按钮样式和定位由[输入区操作弹层统一](./2026-09-12-composer-action-dropdown.md)中的共享组件拥有。

## 替代方案

整个弹层滚动会使搜索和管理入口随选项移出可见区域。虚拟列表增加实现和维护成本，当前几十项列表使用原生滚动即可满足需求。

## 后果

筛选只作用于已加载的普通智能体，不改变后端可见性与当前对话绑定规则。选择器复用现有输入框、图标和主题变量，无新增依赖。这是范围明确、可在同一变更验证的界面修复，直接记录实现决定。

## 验证

通过开发环境真实页面检查搜索、无结果、清空、切换、重开重置和 Escape；在桌面、窄屏和横屏检查面板边界与列表滚动。将面板限高临时移除时，视口溢出检查必须失败。前端单测和构建验证其余集成行为；全量 lint 的既有失败与本次文件检查结果在交付报告中分别说明。
