# 元垒品牌视觉身份

状态：已实现
类型：产品品牌差异
主要 Owner：文档站主题与静态资源、Web favicon

## 需求与失败场景

元垒定位为个人与企业的 AI 中枢、总裁办和 CEO 办公室。沿用 Yuxi 的黄色吉祥物、字标或外部分享图，会让浏览器标签、首页和社交卡片继续表达上游身份。

## 必须保留的业务语义

- 元垒使用独立的“中心枢纽 + 四向垒块”图形和青蓝、深靛色系，不使用上游黄色品牌图形。
- 小尺寸 favicon、深浅背景字标、首页入口图标和分享图保持可识别的同一视觉语言。
- 文档首页实际装配元垒组件；元数据与静态资源指向元垒身份，不指向上游品牌。
- 公开分享图只有在部署站点确实提供该文件后，才能算完成线上传播验收。

## 与 Yuxi 的边界

这是一项有意的产品差异，不改变 Yuxi 的业务能力。上游产品截图和第三方供应商标识可继续用于说明能力，不作为元垒品牌资产。

## 稳定集成点

| 集成点 | 职责 |
| --- | --- |
| 文档站主题和首页组件 | 装配元垒首页、颜色与入口图标 |
| 文档站静态资源与 head 元数据 | 提供 favicon、字标和分享卡片 |
| Web 静态资源 | 与文档站共享 favicon 图形 |

## 上游依赖

依赖 VitePress 的主题、静态资源和元数据装配方式，以及 Web 应用的 favicon 引用约定；不依赖上游黄色图形的具体路径或实现。

## 合并判断

同步上游时保留并迁移元垒视觉身份；可吸收上游首页的功能性改进，但不能恢复 Yuxi 字标、黄色品牌或外部 Yuxi 分享图。

## 替换或删除条件

只有产品身份再次明确调整，或上游提供满足元垒品牌语义的等价方案时，才以新决策替换本差异。不能因上游文件冲突而直接删除。
