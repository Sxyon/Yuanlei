# 元垒决策记录

本目录保存元垒主动新增、扩展或偏离上游 Yuxi 实现的决策。生命周期、文件名、类型、必需标题和证据矩阵沿用[工程决策记录](../../decisions/README.md)，上游决策仍归 `docs/develop-guides/decisions/`。

## 与上游决策的边界

- 上游决策记录解释 Yuxi 当前行为，元垒记录解释与上游不同的部分；不要改写上游记录来解释元垒行为。
- 每条元垒记录在「问题」中陈述上游现状，在「决策」中写元垒改法和与上游的边界，在「后果」中写上游合并注意项。
- 触发条件：功能依赖上游没有的持久化结构；改变上游已有行为；与上游新版本可能冲突的取舍；治理与流程规则本身。
- 上游完整吸收元垒差异后，把记录移入 `archived/` 并在功能索引标注「已回归上游」。

## 目录

- `implemented/`：已生效的元垒决定。
- `proposed/`：尚未实现的元垒提案，验收标准必须包含六列证据矩阵。
