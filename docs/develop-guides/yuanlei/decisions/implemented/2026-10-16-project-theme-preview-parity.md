# 项目主题真实页面只读预览与管理弹窗

状态：implemented
类型：bug-fix

混合资料页及临时文件映射部分由[真实消费决策](2026-10-17-theme-evidence-consumption.md)接续；下文混合包合成预览是此决定形成时的边界，当前仅纯区块历史包保留该路径。

资料接续：文中旧章节编号与执行状态属于原决定时点，原稿可从Git提交`63dc5af7`恢复；现行设计、维护和状态从[专项入口](../../../../元垒系统架构规划设计/README.md)进入。

## 问题

准确包已经加载，但整项目预览仍由独立CapabilityPreview模拟，导航、布局及默认总览与正式项目不同。主题管理的分配表单挤占目录，正常导航常驻恢复链接混淆正常操作与故障。用户逐项要求分配弹窗、工具栏及历史／追溯整理，指出预览缺口并要求纠正恢复逻辑。

## 决策

项目主题设置复用原选择器放入弹窗，保持准确版本、项目、文件、预检、草稿与提交核实，不增加绑定入口。按钮依次为项目主题设置、建立来源、help图标；历史图标在来源目录标题旁切换历史；版本引用及摘要直接显示。

完整能力主题从版本或已保存候选进入临时项目预览URL，使用有权项目真实数据、同一ProjectLayout和全部原能力页面。正文inert只读，导航可切页面；预览不会写绑定或办理业务。没有目标时先选有权项目。准确不可变version或候选source＋revision由服务端重新读取；候选变化、权限或包错误显式失败。预览有临时提示、返回已保存主题及进入原项目主题设置的确认入口；离开预览后正常导航不保留恢复按钮。ABI1区块／混合展示仍使用原只读ThemeHost及合成适配，明确类型范围。

这将当前整项目预览从合成演示改为有权真实数据的只读呈现，须同步SYS／DEV。预览意图是路由阅读上下文，不拥有持久选择；不创建第二套存储、启用或临时绑定。原项目编辑进入／离开预览前处理草稿；旧请求不能盖新引用。选择器内预览另开只读页以保留选择草稿。

## 替代方案

继续补模拟页面仍会持续漂移；复制九套只读模板增加权限和呈现分叉；先写绑定再观察会使预览产生持久副作用。复用真实路由与页面并使正文只读，让同一渲染Owner证明效果，代价是需有权项目与显式临时状态。

## 后果

真实数据预览必须继续原认证及Project可见性，不认为预览绕过权限。临时引用不改变发布、generation、文件或权限。S05-R2双数据、S06、协作和Andon不在本包范围。inert是产品只读控制，原后端仍拥有业务授权；临时页面不设计新的权限边界。
