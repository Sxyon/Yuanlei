# 议题历史目标与验证条件进入执行资料

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/project_work_context_service.py

## 问题

议题修订保存预期结果和验证条件，但执行资料只包含标题、正文，执行者无法收到所选议题的完整业务依据。

## 决策

从选定历史修订生成标题、正文及非空预期结果、验证条件，并在资料卡片标明议题修订。预览、预算、指纹、冻结和发送共用该正文；选定议题超出预算时明确拒绝，不静默删除目标条件。工作验收条件仍有独立来源，旧执行不回填。

## 替代方案

读取最新目标会污染历史修订；新增独立上下文存储会复制既有事实；自动截断条件可能把所选依据改变为另一项要求。

## 后果

目标及条件保持可选，旧资料不足可见。过长议题需要明确精简或手动摘录，不能冒充完整注入。

## 验证

以特殊文本仅存在于旧目标和条件的历史 fixture 验证预览、冻结、实际输入；新修订不污染旧尝试，超预算与空值有独立断言。真实文件交付与浏览器复验的事实另见收尾验收记录。
