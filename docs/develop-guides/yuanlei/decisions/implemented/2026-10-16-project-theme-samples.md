# 当前样例目录、共同基础界面与有限呈现

状态：implemented
类型：feature
Owner：web/src/layouts/ProjectLayout.vue
关联 Feature：[项目主题](../../features/project-themes.md)

## 问题

四个早期与整项目内置来源混在当前选择目录，调研版本缺少可辨组织差异。缺页自动继承让三页包仍显示九项导航，默认与应急独立声明存在漂移。主题管理同时暴露历史演示、工程说明与重复导航，人工刷新不能保证操作后目录可信。

## 决策

正常目录展示默认项目管理、精简专注推进及调研阅读工作室三个独立来源的3.0.0不可变版本。旧四来源在内置登记Owner以既有disabled语义退役，历史区追溯；保留原包、绑定及generation，不自动迁移或升级。撤回状态优先保留，不被登记恢复。

ProjectLayout与OverviewWorkspace消费ABI3有限presentation和hiddenCapabilities；formatVersion保持1。基础总览必须可见，隐藏只缩小主导航，准确对象及办理路由使用完整可信能力并可返回主题总览。缺省缺页继承保持，默认与无包应急都使用原九项基础能力和人工样式；应急只加故障提示及恢复入口。精简总览仅组合蓝图和最近动态；调研使用原Topic正文／预期结果、原决定和蓝图／动态侧栏，不生成批准或新业务状态。Pydantic契约、导出Schema及前端加载边界同源校验；yuanlei v41只放宽主题ABI约束，保留旧ABI1／2和项目选择。

主题管理移除正式S03固定样例页及加载器，旧书签重定向到主题管理；原协议fixture、块渲染与准确候选／版本预览保留。维护说明按需展开，删除重复返回列表与手动刷新目录。目录随来源切换、创建、编辑、发布、维护和分配后以及聚焦时回读，不覆盖候选草稿。初始目录与后续核对共享请求序列，过期成功、错误与busy结束都不能覆盖新操作。

## 替代方案

仅改颜色无法表达用户要求的内容组织；仅删page会被继承逻辑补回。物理删除旧版本破坏持久绑定，原版本原地改字节破坏摘要承诺。复制三套业务页会分叉权限和历史；自由CSS／脚本扩大信任边界。保留S03固定演示会继续把旧样例和正式可选版本混淆。

## 后果

新增ABI3要求配套宿主和yuanlei v41部署，旧宿主明确拒绝新包。有限呈现需要两个真实消费者，维护成本限定在导航和总览，原办理能力复用。旧选择在用户显式切换前仍加载历史定义；退役不改变业务权限。预览继续使用合成数据，不成为真实保存／批准证据。新版本不自动替换选择，故障不回写默认。S05-R2双JSON／PNG联合验收及S06、协作／Andon仍未完成或暂停，不以本包布局证明代替。
