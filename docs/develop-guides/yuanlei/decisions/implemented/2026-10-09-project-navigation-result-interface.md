# 项目空间导航与准确结果办理的首个界面实施包

状态：implemented
类型：architecture
Owner：web/src/layouts/AppLayout.vue

用户已批准导航职责、管理/业务分工和准确结果办理边界，授权 P1a/P1b/P1c。界面首包的实际证据由[U5 实施与验收记录](../../../../元垒系统架构规划设计/第一阶段专项/信息架构与Dashboard-U5首包实施与验收-2026-10-09.md)拥有；动态 Dashboard、模板与 Agent 维护生命周期保持后续范围。

## 问题

上游 AppLayout 拥有全局聊天与菜单，元垒项目需要独立身份和稳定工作入口。两套宽菜单压缩观察与办理正文，项目页面单独运行也无法证明宿主连续性。结果详情需要准确定位同工作不同交付，核对提交时依据、当前条件差异、文件与个人意见；当前后端已经拥有验收、版本和工作完成守卫。

## 决策

平台宿主拥有全局入口和布局偏好；项目布局拥有当前项目身份及概览、工作台、工作、项目智能体与资料入口。Dashboard 内容拥有自身观察与分析。新用户默认平台窄栏，显式展开为覆盖，固定为占位；已有 sidebarCollapsed 布尔偏好保留。项目折叠按用户和项目保存，窄屏临时呈现独立于桌面偏好。宽度、密度和断点保持可逆假设，悬浮与拖动保留研究出口。

项目默认打开管理概览，业务大屏以查询视图切换。管理读取、业务 HTML 读取和蓝图读取分别呈现加载与失败；业务失败时管理入口持续可达。静态 HTML 沿用空 sandbox 与无网络 CSP，平台不向其注入事实、偏好或消息桥。治理工作台承载蓝图、议题、决策和建议准入；正式工作承载人工交付与办理；项目智能体入口列出绑定并进入既有执行工作台。人工工作沿用直接创建路径。

工作详情通过既有 project/task/result 与锚点聚焦准确交付，首层提供标题、摘要、提交时条件、文件与动作；历史、来源、执行、Git、Issue、附件与设置按需展开。已接受当前结果的工作可调用既有完成流程。来源返回仅采用同项目及指定全局来源路由，否则回工作列表；来源页按完整路由恢复会话内滚动和准确链接焦点。聊天与其他缓存页面的宿主持续挂载，并以组件身份区分缓存，以用户身份隔离会话。

个人验收意见按用户、项目、工作、结果存于当前标签页会话缓存。结果切换与刷新恢复准确意见；409 保留输入，要求重新核对后再操作，已被他人处置的结果保留只读本地意见。成功清除该结果意见，无权清除对应范围，登出、登录和换账户清除会话缓存及来源位置。页面切换使旧异步响应失效；缓存不拥有业务状态或授权。

前端复用现有 API，权限、对象归属、条件修订、幂等与完成守卫仍由 backend service/repository 最终执行。首包无 schema、后端业务语义或运行时协议改动。

## 替代方案

- 默认悬浮自动展开：鼠标进入效率较高，触屏和键盘需要另一套交互；自动收起还会混淆手动偏好。显式按钮与固定态覆盖首包场景，细指针实验另行验证。
- 同时固定两套宽菜单：入口文字稳定，密集办理可用宽度降低。平台固定保留为个人选择，窄屏临时转覆盖。
- 单层项目菜单：项目任务集中，全局聊天、跨项目收件箱和 Agent 管理的归属难辨。稳定平台外壳保留这些入口。
- 所有结果连续铺开：比较直接，但长条件、多份文件与意见容易混淆办理对象。结果选择器提供准确身份和摘要，单个结果展开条件与操作。
- 在生成 HTML 中加入钻取桥：当前无脚本隔离模型无法承载该能力。动态数据与准确导航契约由 D2 单独闭合。

## 后果

本决定取代[默认 Dashboard 与工作台导航](2026-09-26-default-project-dashboard.md)的展示切换与入口部分，其授权、无消息桥与默认定义不持久化边界继续有效。

宿主布局和 ProjectLayout 必须保持稳定，项目列表临时失败不能销毁子页面草稿，跨页缓存必须有准确组件 key。后续上游 AppLayout、RouterView 或 Workspace 路径更新需要复核这些边界。意见仅保证当前标签页会话内恢复，缓存不可用时仍可办理；它不是持久业务意见或跨设备草稿。

管理与业务读取互不阻塞，生成页面不修改平台偏好。静态业务页具备观察和页内锚点能力；准确对象钻取及完整返回链待 D2 实施。界面分项实施不代表专项整体完成，用户阅读观察、实际触屏和辅助技术仍可触发呈现调整。模板版本、Agent 工具、自动启用与回退需要独立增量和生命周期验证。

## 验证

针对性 Web 测试覆盖真实宿主模板缓存切换、来源位置恢复、准确锚点、账户与对象意见隔离、刷新和冲突、旧条件与缺失快照、成功及无权清理、Git 完成入口、独立加载与过期响应。浏览器在已授权隔离项目中创建人工工作，形成两版条件和两份结果，当前结果接受后完成；另一标签页产生真实 409 且保留只读意见。数据库分别回读工作、结果修订与状态、空治理来源和零执行尝试，个人空间回读合成文件正文。

实际页面验证平台→项目→管理→准确旧结果→来源、筛选/滚动/焦点恢复、聊天输入跨缓存页保持、深浅主题与真实 390px 视口。验收范围、实际命令结果、独立 Review 与 Not run 场景由[U5 证据记录](../../../../元垒系统架构规划设计/第一阶段专项/信息架构与Dashboard-U5首包实施与验收-2026-10-09.md)统一拥有；其未验项继续约束交付判断。
