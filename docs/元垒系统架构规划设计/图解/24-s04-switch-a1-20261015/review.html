已确认绑定：调研 2.0.1 / generation 8。

包无法加载或宿主渲染失败。绑定仍指向该版本。

若提交响应丢失，尚未核实

显示“保存结果待核实”，先 GET 当前绑定。核实到目标后接续加载；仍为原选择则重新确认；发现其他选择则按冲突处理。

GET 也失败时保留核实入口，禁用再次提交；不盲目重发，不自动回滚。

R4 · 可信恢复入口

正在使用应急基础界面

持久选择仍是 调研 2.0.1 / generation 8。此界面不是已切回默认主题。

宿主提供设置／选择入口及项目列表出口，目标主题缺设置页也可恢复。

项目权限失效

立即清空项目数据、对象与草稿；不展示应急业务界面，仅保留“返回项目列表／重新登录”入口。绑定不自动改变。

M7 · 刷新 / 新标签 / 重新聚焦

正在核对项目当前主题

从服务端读取当前绑定后再认定版本；所有标签按 Project ID 隔离，共用 Workdir 也不共用选择。

若发现另一窗口已改选择，提示旧版 → 新版及 generation。保护本标签未保存输入，再接续新上下文；核实期间不把旧界面标成当前已应用。

存在草稿时：默认返回编辑，显示其所属旧版与准确业务对象；保留草稿，完成处理后进入新选择。失权优先清空。

主题缓存按用户／Project／版本／generation 隔离；业务草稿按用户／Project／业务对象隔离。聚焦事件本身不提交绑定。

集中审阅：推荐这一组交互

  1. 项目设置直接打开同一选择浮层；当前版本置顶，候选维护与发布另在原入口。
  2. 应用前返回编辑或明确放弃；成功统一回读后，无对象进入总览，有准确对象按稳定能力保留。
  3. 冲突需重新确认；保存状态、加载状态和应急界面分别表达，可信选择入口始终可达。

替代：只在平台主题库选择会增加日常路径；保存后强刷会损失未保存输入。推荐在现有设置卡片局部扩展，以唯一宿主上下文接续。
