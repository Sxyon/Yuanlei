## 复现

1. 项目列表→主题管理。工具栏为项目主题设置／建立来源／help，来源目录旁历史图标，版本身份及digest直接呈现。
2. 从精简准确版本点预览版本；无项目先选择A。进入真实项目总览，临时横幅说明目标版本／当前保存，导航只有总览／蓝图／议题，正文只读。主导航可进入原蓝图及议题页。结束预览回读原默认选择。
3. 再从预览的应用此版本进入原选择弹窗，核对目标与精简准确ID并应用；平台回读gen19，再进入项目。focus-preview与focus-applied总览正文及导航相同，只有临时提示／只读状态不同。
4. 同路径调研预览→刷新→新标签，临时版本为调研，持久仍精简gen19。显式确认应用才gen20；research预览／正式正文及导航相同。
5. 默认版本同路径预览，沿九项导航观察原页面只读；应用默认后gen21，默认总览及导航一致，正常无常驻选择／恢复。
6. 弹窗拟用默认时关闭→返回编辑，项目／版本保持；实际议题输入讨论草稿后离开→返回编辑，正文未丢、未发表。
7. 仅隔离A包字节注入损坏→刷新，显示已保存，加载失败＋应急基础界面＋恢复入口，gen21不变；恢复原字节重新核对。未绑定C显示应急恢复入口，gen0不变。
