## 简短人工路径

1. 项目列表→主题管理→平台内置→任一主题：已发布版本有选中态和只读提示，没有编辑或发布操作。
2. 准确版本行→创建可编辑副本：确认新名称、我的主题归属及准确来源；创建后自动进入自己的编辑草稿，看到尚未发布、尚未应用。
3. 编辑JSON中的theme.version及一个已有显示字段→保存并校验→预览已保存草稿：未保存时不能发布，保存后显示新修订，预览仍标当前已保存项目版本。
4. 返回我的主题草稿→发布新版本→确认：自动切已发布版本，看到准确版本、digest与分配入口；项目此时仍旧选择。
5. 分配到项目→核对目标、旧选择、拟用版→应用：结果回读明确更新；继续改草稿并发布另一个新版本，项目不自动升级。
6. 可直接检查隔离数据“M1-制作验例-20261016”：有3.1.0-m1与3.2.0-m1两个发布版，项目A仍选3.1.0-m1／generation22；草稿已保存修订4。检查存储维护应展开才显示健康／残留／异常摘要，清理需另确认。
