## 1. 视觉判断、阅读顺序与修订边界

A 保持主方案。稳定项目导航承担项目、工作、工作台、智能体和资料入口；管理概览负责发现待处理，业务观察负责解释数据与准确导航。B/C 继续只有高频处理和观察返回切片，未扩展成三套完整应用。研究工具栏的状态/主题/方案按钮是实验控件，不属于拟定产品首层导航。

管理概览的判断顺序为：分开的治理/正式工作/结果/异常摘要→准确待验收结果→风险与介入→当前依据与进展。四项计数保留独立语义；结果数含旧提交，显式显示当前要求与旧提交各多少。待验收列表把当前要求结果放前、旧提交仍可找到，防止把历史待验收直接当本次可办结果。摘要卡顺序仍待人类连续任务反馈，未凭作者审美正式决定。

结果详情的推荐阅读顺序为：持续身份（项目、工作编号、选中结果）→当前/旧依据状态→结果摘要→提交时条件及当前差异→文件→意见与办理。旧依据限制前移到摘要之前，结果身份旁直接标“旧依据·仅供对照”；当前结果明确可核对办理。完整条件、来源和历史按需展开。详情归属工作导航，管理入口仍稳定可达。A 重复项目徽标和侧栏重复身份被收紧，B 保留项目徽标以帮助跨项目辨认。侧栏解释“接受结果”和“接受并完成”的不同后果，而非再复制同一组身份。

原型的连续任务说明使用显式前后切换；切换说明不自动导航、不提交办理、不声明完成或通过。它帮助用户完整体验，仍需用户主动核对和操作。五项已确认信息要求不改变；暂定呈现调整、脚本事实、用户反馈与正式决定保持不同状态。

## 3. 同一小空间的 R1 扩展与 R2 对照

空间入口为隔离服务 `spatial.html`。同一 `spatial/scene.json` 拥有示例 A 的 12×8 示意坐标、四个矩形区域、状态、五点绕行线和业务对象引用；宿主通过有界 GET 取得并校验一次快照，两侧消费它。任务为辨认 C 区物料阻挡、看 A→D 绕行关系、点击 B 展台进入 CG-013/R4，再返回空间观察。数据单位为示意米，路径由源给定，没有测绘、自动避障或真实通行建议。

| 对照维度 | 有限 R1 扩展 | R2 隔离 Vue |
| --- | --- | --- |
| 表达效果 | 新增一个 coordinate-map 素材，消费有限矩形、状态与折线路径；保留旧四类素材的拒绝证据 | 固定手写 `Scene.vue` 编译后运行，独立模板和状态可以表达同一图；未由 Agent 生成 |
| 同尺度结果 | 与 R2 的四组坐标/尺寸和折线 points 相同；阻挡轮廓、标签与路径可见，可隐藏路径、切主题 | 同源、同几何、同任务；选择区域后提出对象导航，经宿主进入同一 R4。当前小任务没有展示 R2 额外自由度优势 |
| 依赖与装配 | 复用 Vue 3.5.41 runtime-only 及宿主可信呈现；无新增库/构建流程 | Vue/编译器 3.5.41 与 esbuild 0.28.2；SFC 预编译并含 Vue 的本地 IIFE 包约 58 KB，精确字节与摘要由 `spatial-build.json` 拥有；浏览器不编译模板 |
| 输入与导航 | 有限定义拒绝 code/project/URL 等扩展输入；宿主几何校验拒绝越界、超量和不支持版本 | iframe 只收已校验快照，不自行取业务数据；对象请求须对应当前选择，额外 URL 被拒绝；真实后端仍应最终执行权限 |
| 失败行为 | 空场景与源错误分开；越界输入拒绝，保留旧有效场景/时间 | 语法和未许可依赖在本地构建拒绝；缺包与运行错误显示失败，R1 保留。保留 R1 不算 R2 通过 |
| 维护代价 | 可信素材代码、定义/schema 与消费者兼容要共同维护；新增能力进入所有消费端的验收范围 | 各代码包/编译依赖、CSP、消息桥、错误和版本需要维护；当前每个包含运行时，尚无多包缓存/运行时复用方案 |
| 已知表达边界 | 有限矩形和折线，无曲线、任意图层、热区、自动寻路或编辑器 | 理论可由代码扩展布局与状态，但本次没有验证这些额外能力、任意依赖或任意生成代码 |

R2 使用 `sandbox="allow-scripts"`，不设置 same-origin、顶层导航、表单和弹窗许可；srcdoc 为 opaque origin。宿主核对 message 的 source、opaque origin、当前装载 channel、消息种类及准确对象。允许对 opaque frame 使用 `*` 发快照，但目标 Window 为当前 iframe；子页回复固定宿主 origin。CSP 以 bundle 内联脚本 hash 放行，禁止连接与其他资源；构建摘要只核对字节身份，不证明来源签名或供应链可信。这些做法参考 [MDN iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)与 [postMessage](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage)；Vue 的预编译/运行时分工参考 [Vue 渲染机制](https://vuejs.org/guide/extras/rendering-mechanism)。来源访问日期为 2026-10-08。

浏览器实测探针对宿主 DOM 和 sessionStorage 返回 SecurityError，网络 fetch 被 CSP 阻止，任意 URL 导航请求被桥接拒绝；宿主 DOM 哨兵和存储值均没有改变。其他 opaque 窗口和旧 channel 使用实际 postMessage 负向输入，非当前对象在桥接处拒绝，错误摘要在加载前拒绝；错误 origin 通过人工 MessageEvent 注入验证 handler 边界，未把它宣称为真实跨站通信。刷新与空场景同步清除两侧选择，主题/路径切换保留有效选择。固定样例的 R1/R2 几何和准确返回链通过，深色/390 px 无文档横向溢出。尚未证明任意恶意代码、资源耗尽、CPU/内存配额、超长循环抢占、完整 CSP 绕过防护、跨浏览器隔离、独立构建执行沙盒或真实私有数据安全。本地编译器只处理固定手写样例，未把浏览器隔离扩大成任意源码的构建授权。

该小任务已被有限 R1 忠实表达，第一轮“素材集合不足”没有扩大为“受控架构不足”。暂定以 R1 支持已闭合的常规及有界空间任务；R2 保留局部创作路径，下一次出现有限表达需要大量专属素材或丢失关键关系的真实需求时，再比较收益和代价。一个通过的小空间不能把受控组件冻结为所有创作的上限，也不支持提前建设通用编辑器或整体迁移。
