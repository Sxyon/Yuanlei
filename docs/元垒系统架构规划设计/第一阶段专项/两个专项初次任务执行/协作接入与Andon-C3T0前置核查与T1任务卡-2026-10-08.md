# 协作接入与 Andon：C3/T0 前置核查与 T1 任务卡

日期：2026-10-08，执行状态更新于 2026-10-09。类型：前置核查与具体试验卡。读者：用户、试验执行者与 Reviewer。继承 [C2 方案比较](协作接入与Andon-C2端到端方案比较-2026-10-08.md)，只落实单次准确交付前置条件；方案取舍继续由 C2 解释。T1-O 已获整卡授权并执行、清理，实际结果由[协议试验报告](协作接入-C3T1O协议试验结果-2026-10-09.md)拥有；本页保留准备时事实和原卡范围。T1-M 尚未派发，产品接入和业务批准仍未实现。

## 1. T0 结论与推荐

两平台实际连接和目标已定位。Multica 选定指定工作区内的普通 Codex Agent 作为基线，排除系统 Mika；OpenClaw 选定现有 `analyst` 作为配置/身份基线。现有目标的执行边界均未满足 C2 的受控文本试验要求，不能把新 issue/session 当成宿主隔离，也不能用“请勿调用工具”替代工具策略。

推荐先领命 OpenClaw 的“专属无工具 Agent 准备 + 一次文本协议探针”组合卡；它需要明确覆盖新增专属配置的授权，原日常 Agent 保持原配置。Multica 的工作区、Agent/runtime、权限和协议范围已经填实，但宿主隔离门槛仍未通过，暂不推荐给日常 Codex runtime 发任务。其卡先交给执行环境 Owner 证明边界，符合卡内条件后才能领命准确交付试验；增加 VM、账户或 daemon 是另一项环境授权，不能由试验者临时安装或调整。

两份 T1 卡均采用文本交付；可选摘要、依据、发现与风险随同一次任务返回，纳入同次观察的 T2。文件、求助、恢复和正式授权试验留后续，不为了得到补充追加评论、消息或 Run。独立止损任务可先于两平台试验落地。

## 3. 两卡共用的固定输入、证据与执行约束

试验输入为 C2 的人工 fixture：A 在 2024—2026 含税金额 100/110/120，B 为 120/110/100，C 为 90/100/110，单位为同一虚构金额单位。所有资料随请求正文给出，不提供目录、URL、业务账号或真实文件。平台不同仅换 operation/nonce，业务输入相同。

一次输入请求执行者交付：operation/nonce、三家的总额与均值、最低成本结论；随后附不超过 200 字的摘要、依据和风险。预期 A=330/110、B=330/110、C=300/100，最低为 C。执行者应说明结论只适用于给定虚构资料。摘要未提供仍可判断正式文本交付；风险或执行失败不能被折叠成成功补充。源码/调用记录证明来源，独立计算证明数值，执行者的“已通过”只记自述。

初轮只请求文本。OpenClaw 原生目标准备的模板/状态写入和专属目录内 Git 初始化单列在 T1-O，执行者不获得 Git 工具权限。探针可以把实际响应与正式文本保存到受保护本地证据目录，属于调用者存证，不称远端文件交付。生成/下载远端 table.csv、执行者操作宿主目录、安装或调用 Git 工具、渠道发送、自动再委派、正式治理批准都不在这两卡范围内。T2 同次补充不产生额外调用；若原输出缺补充，记录缺失即可。

| 共同执行规则 | 固定范围与判定 |
| --- | --- |
| 调用次数 | 每卡至多 1 次产生执行的逻辑提交；每 6 秒一轮，前 120 秒最多 20 轮，每轮最多 3 次只读请求，共最多 60 次轮询请求。明确说明平台内部 retry 属平台行为，全部记录；归属出现歧义立即停止新动作。调用方不自动重发创建或 agent 请求 |
| 资源 | OpenClaw 请求执行 timeout=60 秒，后续需要证明它是实际运行截止而非只观察超时；Multica daemon 绝对截止尚无有效部署证据，不声称 60/120 秒停机。20k token 仅为观察门槛；未取得提供者价格/硬限额证明，授权卡须明确接受一次现有模型账户的计量使用，要求硬金额限制时不派发 |
| 终态超时 | 120 秒后停止新投递和高频观察，在已登记对象上最多再观察 5 分钟、最多 20 次只读回读并办理清理；至多提交 1 次准确取消。取消失败/无法证明停止则保留“执行可能继续”，不能清理仍使用的目录或报已停 |
| 停止条件 | 目标/版本/配置变化、控制身份无权、越出范围、运行无法唯一归属、收到描述而非输出、工具边界缺失、非本卡对象受影响、预算异常、终态/取消未知；停止新动作并保存明确的待处理项 |
| 响应丢失 | 先回读同一 operation/session/触发/Run。仅只读重试；无法确定接受情况时不再发送。需要第二个尝试则另领命，不能由“可重试”自动扩大本卡范围 |
| 完成证据 | 提交意图/输入指纹，准确 Agent/runtime 或 session/runId，平台接收与终态来源，当次正式输出及同次可选补充，独立 oracle，是否产生非许可工具动作，实际清理结果。缺任何归属证据则该层不通过 |

T1 通过只证明相应版本、身份、目标和路径的协议交付。它不证明元垒自动映射/落库、结果唯一导入、产品权限、业务接受、原运行续接或 Andon。shipping 入口另做真实 HTTP/PG/worker 与结果回读，继续使用现有 Delegation/ProjectWorkResult Owner。
