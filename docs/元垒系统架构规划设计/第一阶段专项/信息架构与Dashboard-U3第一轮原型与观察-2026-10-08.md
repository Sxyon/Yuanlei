# 信息架构与 Dashboard：U3 第一轮原型与观察

日期：2026-10-08。读者：专项发起者、产品与技术验证参与者。类型：原型研究记录。继承 [U2 比较与暂定推荐](信息架构与Dashboard-U2整体方案比较-2026-10-08.md)、[U0/U1 事实](信息架构与Dashboard-U0U1事实与讨论-2026-10-08.md)与[两专项复核要求](两专项U2C2复核与下一轮推进-5f0d098.md)。目标是用可以操作的页面核对呈现、身份、依据、文件与返回，再独立检验有限 R1 数据/导航与表达力。

## 1. 阶段、入口与能力边界

当前为 U3 第一轮隔离原型，A 为主，B/C 仅有对照切片。U2 推荐仍为暂定，未形成 U4 正式 Decision。本轮未修改产品代码、未连接真实业务、未调用智能体、未发布项目 Dashboard；原有人工单结果证据继续引用 U0/U1，不重跑真实业务流程。

产物目录为仓库根的 `research/prototypes/dashboard-u3-20261008/`，独立于 `web/`、`backend/` 和项目 Workdir。启动方式由目录内 README 拥有：在仓库根执行 `python3 research/prototypes/dashboard-u3-20261008/server.py`，使用回环地址端口 8767 打开原型。服务仅有合成读取与对象导航 GET；视觉办理保存到原型 sessionStorage。关闭服务用 Ctrl+C；重置只影响原型状态。

| 入口路径（相对隔离服务） | 可操作内容 | 明确未实现 |
| --- | --- | --- |
| `index.html#a/alpha/overview` | 稳定项目导航、默认管理概览、工作列表、准确多结果办理、文件轻量/独立查看、采购业务一屏核心视图 | 正式创建/上传、真实审批/验收、产品登录、数据库、真实证据快照 |
| `index.html#b/alpha/queue` | 高频跨项目并置办理、同标题不同项目、已读未答/已答未恢复的入口保留 | 完整 B 应用、真实收件箱聚合、问题送达/采用/恢复协议 |
| `index.html#c/alpha/business` | 同一业务观察、月份筛选、全屏→准确办理→返回原画面/筛选→退出 | 完整 C 双模式系统、真实业务大屏部署 |
| `lab.html` | Vue runtime-only 有限定义、合成 HTTP 取数、项目绑定与准确对象导航、负向拒绝、空间结构压力比较 | 产品加载/存储/发布契约、真实权限与源接入、Agent 生成、R2 隔离代码运行 |

每页标记合成数据，操作范围说明随入口可达。共用两个项目、同一批工作/结果/问题及模拟状态，公平复跑每套前重置。文件独立页显示准确项目/工作/结果；PDF 快速查看标明分页模拟，独立出口提供 12 页合成 PDF，未宣称元垒 PDF 引擎通过。

## 2. 共用任务与同尺度对照

合成数据 Owner 为原型目录内 `data.js`；检查脚本与实际结果分别为 `check-prototype.cjs`、`evidence/checks.json`。项目 A“采购协同”和项目 B“展陈筹备”有同名工作，项目、工作编号、结果和条件版本不同。A 的 CG-012 含旧要求 v1 下未接受 R1、旧要求 v1 下待验收 R2、当前 v2 下人工交付 R3；执行失败 E1 没有正式结果。其他工作还有待验收 R4。结果计数与工作计数分开，接受并完成 R3 后保留 R2 的历史待验收状态，禁止从邻近尝试猜测结果。

| 共用任务 | A 路径与可观察结果 | B/C 对照及解释 |
| --- | --- | --- |
| 打开项目、发现待验收 | 管理概览分别显示待结果与涉及工作；点具体结果进入详情。项目切换与工作、文件入口稳定保留 | B 直接处理跨项目队列，项目上下文在详情身份区保持；B 只验证办理切片，不承担全项目导航质量结论 |
| 核对旧依据，再办理当前结果 | 打开 R2，填写意见，接受被旧要求原因拒绝；切 R3，摘要、提交时条件、当前条件、交付和办理均可取得 | B 使用同一详情内容与结果选择器；并置队列减少页面切换，也增加横向密度。两者都禁止把旧依据当当前依据 |
| 看文件、保留办理意见 | Markdown/图片轻量查看；关闭或 Escape 回选中结果与触发焦点。独立文件页显示完整身份和准确返回入口；原页意见保留 | 不同文件采用组合出口。PDF 快速查看为标注的分页模拟，12 页样本独立打开供长文阅读；Office、超大文件与真实转换尚未实现 |
| 跨项目处理同名事项 | 完成 A 当前结果→回管理→切项目 B→办理 B-R1；意见按项目/工作/结果分别保存 | B 队列选 B 同名事项，身份改为 B，办理 B-R1；不能只凭标题确认对象 |
| 业务观察进入办理再返回 | A 业务页与管理概览可切换，业务页以观察、分析和准确导航为主 | C 选 8 月→全屏→R3→看文件→回原业务页仍为 8 月/全屏，Escape 退出；来源记录经当前标签页重载保留 |
| 已读、答复和恢复区分 | 跨项目收件箱入口有独立业务阶段 | B 的 Q1 已读但待答；答复后进入“已答复·未恢复”，与原 Q2 一起仍可找到。没有模拟成恢复成功 |

固定脚本从各方案的全新状态执行“拒绝 A 旧结果→核对 A 当前文件并接受完成→办理 B 同名结果”：A 10 次点击/选择、5 次 hash 路由变化；B 8 次点击/选择、0 次 hash 路由变化，均准确办理 2 个当前结果。计数排除文本填写、滚动、耗时和认知成本；A 结束于 B 详情，B 结束于队列详情，终点形式不同。该数值仅证明此路径的导航差异，未证明人类效率或总体优劣。C 复用业务观察任务，不纳入跨项目效率排名。

蓝图/议题/决策链、人工创建、Agent 接收/执行/异常、草稿与启用版本在工作台及维护入口展示职责和未实现范围；本轮没有完整模拟研讨到执行、智能体工作台或模板管理应用。它们继续由 U2 场景地图拥有后续需求，不能因本轮切片缺失从专项范围删除。

## 3. 自查观察与呈现判断

检查使用全新浏览器上下文和合成状态；没有读取用户已登录浏览器。`evidence/` 保存对应截图，DOM 断言与检查结果拥有可复跑事实。视觉审阅覆盖管理概览、准确结果、业务观察、B 队列、深色长文/窄屏和 R1 拒绝/降级画面；不会把截图当交互成功证据。

| 检验条件 | 已观察与处理 | 结论及边界 |
| --- | --- | --- |
| 默认管理层级 | 分开的治理、正式工作、结果验收、当前执行异常；待验收以结果行定位；风险与当前依据次级呈现 | 暂定 A 能承接项目首次进入。8 项工作/3 份待验收的合成规模可读，真实排序、百项密度与用户判断尚未验 |
| 桌面业务一屏 | 1440×1024 默认核心视图含独立指标、趋势、交付关注、数据时间/口径、管理与维护入口；明细按需展开 | 默认核心不需要页面滚动；展开和长标题会增加高度。未承诺所有尺寸、所有数据均一屏，窄屏采用连续阅读 |
| 办理密度 | 身份、选中结果、摘要先呈现，长条件/差异按需展开；桌面历史与辅助信息侧列，窄屏移至下方 | 窄屏保留顶部结果选择和“到办理意见”入口。五项办理信息可取得，不将长条件与文件全文挤进首屏 |
| 深浅主题与窄屏 | 390 px 检查概览、长标题详情、业务页和 B；文件面板随窄屏展开，R1 为单列；页面无水平溢出 | 已检查局部表格/导航可横向滚动的合理出口。尚无屏幕阅读器、触摸设备或完整对比度审计 |
| 草稿与依据 | 意见按项目/工作/结果隔离；切结果、看文件、重载、版本冲突/源失败不清除草稿；旧要求接受被拒绝 | 仅当前标签页 sessionStorage 保持；跨设备、关闭后恢复、服务器并发及用户迁移未实现。合成条件不证明真实历史证据不可变 |
| 返回连续性 | 文件关闭回触发焦点；独立文件返回准确结果；C 月份/全屏来源经重载保持；Escape 退出全屏 | 不将所有办理表单嵌入大屏。浏览器历史、复杂嵌套来源与对象删除的完整产品策略尚未验证 |
| 空/错/加载/失效/冲突 | 空项目有人工独立入口；读取失败保留旧参考并阻止提交；失效文件/版本冲突拒绝且保留意见 | 创建入口是表单演示，不实际创建。冲突为可控场景，未实现服务器版本协议；源失败与零数据区别可见 |

文件组合的暂定理由保持 U2：短 Markdown 与图片就地核对便于保留意见；长文、PDF、大文件与对照阅读需要独立出口。原型只实现合成 Markdown、SVG 和 PDF 模拟/独立样本，不把文件类型标签当真实转换能力。预览与独立查看共存后，下一轮应观察用户是否仍丢失对象身份或核对依据，再决定支持范围和交互细节。

## 4. R1 有限契约与表达力压力

视觉原型没有使用 R1 渲染器；它们可独立调整。技术页使用当前安装的 Vue 3.5.41 runtime-only，可信呈现代码消费四类有限定义：指标、趋势、表格、说明。宿主提供当前项目与绑定，定义没有项目选择、任意路由、事件代码或可执行模板字段。合成 GET 返回数据截至时间、读取时间、单位、缺数/过期状态；准确导航由样例服务核对项目、对象种类、工作/结果组合。后端真实权限仍由产品依赖与 repository 拥有，样例白名单拒绝不证明该权限已经验证。

采购样例在 A/B 独立月表之间切换；B 缺同比基期显示缺数，空值不按零计算。源失败显示结构化错误并保留成功快照和原时间，刷新不假造新源日期。实际 HTTP 负向样例拒绝跨项目绑定、跨项目对象、结果/工作错配；定义校验拒绝项目注入与事件代码。各拒绝旁有可观察记录，而非成功提示遮盖失败。

第二种要求为展陈区域巡看：区域按坐标布置、物料阻挡标注、入口到出口路径叠加。它使用独立 `spatial-alpha`/`spatial-beta` 合成源；不能用采购卡片换标题冒充结构变化。目标图明确标为 A 手绘参照，受控定义中的 `spatial-overlay` 被有限素材集拒绝。已有表格可以显示区域/状态，但丢失几何位置、阻挡与路径关系，因此清单降级不满足该任务。未为了过关添加专属空间组件、任意脚本或长 DSL。

证据说明当前四类素材不能忠实表达这一空间要求；尚未证明所有受控架构都无法扩展，也未证明 R2 已安全可用。R1 继续作为常规管理和有界数据/导航的研究基线，素材集合不成为创作上限。下一轮保留同数据、同任务的两条独立试验：一条验证小型通用空间素材能否完整表达坐标/路径、保持可验证性；另一条研究生成 Vue 经构建及隔离加载的 R2。比较表达保真、依赖与构建成本、主题/窄屏、权限和导航约束、故障回退；若扩展仍需要大量业务专属素材或绕过校验，提升 R2 的优先级。R2 仍须证明隔离与受控桥接，不能直接解除现状静态 HTML 限制。

## 5. 暂定推荐变化与下一轮操作计划

A 保持主推荐：项目壳、管理兜底、业务观察和准确详情能共同承接发现到办理。B 的固定任务有较少切换，建议保留为跨项目高频处理入口的候选；未据此替换项目默认入口。C 的全屏/筛选往返在合成链路成立，建议把它作为业务观察能力，暂不扩大为整套导航模式。文件组合继续试验，不将所有文件统一一种打开方式。

技术推荐增加明确条件：R1 常规样例成立，但空间任务已有不等价证据，因此下一轮应实际比较有限通用扩展与 R2，暂停把四类素材当未来所有 Dashboard 的默认边界。U2 的数据绑定、实例版本、结构共享不携带数据/凭据以及可配置自主维护方向保持；本轮没有存储、模板派生或发布试验证据。尚无正式 Decision。

| 下一轮增量 | 用户能得到的结果 | 前置与验证任务 | 推翻或收缩推荐的证据 |
| --- | --- | --- | --- |
| U3 人工同任务走查 | 判断 A 的五项办理信息是否足够，B 是否值得保留高频入口 | 使用现有合成数据，各方案先重置；要求找到 A 旧依据、核对 R3 文件、准确办理 B 同名结果、描述剩余旧结果；记录误认、寻找、回退、草稿损失，不只计点击 | 用户在 A 反复找不到依据/动作，或 B 并置诱发跨项目误判；先调整层级/身份再进入实现 |
| 业务观察压力补充 | 检查一屏与准确钻取在更密集情形仍可理解 | 可与视觉调整并行；新增明确合成的密集交付、过期/缺数/错源、1280×720与200%缩放；执行 C 筛选→办理→返回 | 被压缩后的图墙误导时间或缺数，返回损失上下文；收缩默认核心，按需展开，不强塞一屏 |
| R1 扩展与 R2 有限对照 | 用同一空间任务决定创作扩展路径 | 在隔离目录中保留既有失败 oracle；R1 通用空间结构与 R2 编译样例分别消费同源。R2 先研究隔离、受控桥接与依赖准入；错误必须保留稳定回退 | R1 需要大量专属组件/DSL，或 R2 无法隔离/稳定构建；分别扩大 R2 研究或保留静态受限回退，不迁移整站 |
| 模板派生和维护协议样例 | 同模板两个项目结构共享、绑定/数据分离；草稿失败不覆盖启用版本 | 等数据/导航与加载契约有足够证据后，模拟版本固定、升级差异、竞争更新、验证失败、回退；工具输入/存储/发布选择分别记录 | 项目绑定随模板升级串入另一项目，自动维护覆盖草稿或启用指针失去问责；收缩自动启用范围并修正协议 |

视觉、信息层级和同任务人类观察可并行；正式模板发布、智能体维护与回退必须等待加载/验证/版本契约。下一轮先用这些明确任务核对整体取舍，不继续局部偏好二选一。目前没有必须先由用户裁决才能完成本轮的授权分歧；后续若真实业务需要自由空间创作而受控扩展代价过高，再带可操作对照讨论 R2 的投入范围。

## 6. 证据有效性与未验范围

文档链接、构建和仓库契约检查只验证材料的组织与可构建性；它们不证明业务设计合格。真实用户观察与真实业务验证仍分开记录。根目录已有用户暂存的复核文档保持原状，本轮不提交、不发布。
